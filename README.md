# SONYMA Eligibility Explorer

Professional pre-screening tool for SONYMA (State of New York Mortgage Agency) programs.

**Prepared for:** Robert Castro · Senior Loan Officer · Movement Mortgage · NMLS #66194

## Live Site
https://sonymacinematiceligibilityexplorerv-phi.vercel.app/

## Features
- Cinematic hero introduction
- Current SONYMA rate snapshot
- Interactive eligibility checker (Achieving the Dream, Low Interest Rate Program, Standard DPAL, DPAL PLUS 2026)
- County-specific income & purchase price limits
- Target Area awareness
- FAQ covering DPAL, first-time buyer rules, recapture tax, and Realtor guidance

## Project Structure
- `index.html` — Main application (self-contained with embedded photo)
- `data.js` — SONYMA income limits, purchase price limits, and rate snapshot

## Deploy to Vercel
1. Connect this GitHub repository to Vercel
2. Framework Preset: Other
3. Deploy

The site is a static HTML + JS project — no build step required.

## Notes
- This is an educational / pre-screening tool only. Final eligibility requires a full mortgage application and SONYMA approval.
- Rates and limits change. Always verify on the official HCR / SONYMA pages.
